Depuis le 15/11 (dépôt public), la protection est gratuite : acceptée avec la demande n° 29 le 15/11 (22 h 57), à poser aux réglages du §3.
- **Compte GitHub séparé pour Claude** (les permissions de l'application ont été mises à jour par Houssem le 13/11) : écarté le 23/10 parce que la protection de `main` suffisait ; rouvert tant que `main` n'est pas protégée.
