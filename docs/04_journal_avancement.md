## Reporté après la mise en ligne (à trancher par Houssem)
Section créée par la demande de changement n° 15 (09/11). Chaque point a son risque ; aucun ne bloque la mise en ligne.
- **Questions juridiques du paquet 7.2** (représentant dans l'Union, RGPD art. 27 ; transfert vers la Tunisie ; statistiques de Cloudflare fondées sur l'adresse IP ; contrat de sous-traitance ; durée des journaux) : **décision de Houssem du 11/11** : mise en ligne du premier lot sans consultation préalable (exception de l'article 27, paragraphe 2, a : traitement occasionnel, aucun cookie, aucun traceur, aucun formulaire) ; **à revoir avant la demande AdSense** (étape 12), un représentant dans l'Union étant probablement nécessaire.
- **GitHub Pro et branche `main` protégée** (pull request obligatoire, contrôles exigés, aucun contournement). Payant, sans équivalent gratuit sur un dépôt privé (ni branches protégées, ni rulesets). Risque : un commit poussé directement sur `main` peut être déployé sans la validation de Houssem. D'ici là : règle « toute modification passe par une pull request » et garde-fou de la CI (étape 7), qui couvre l'accident, pas un compte compromis, et que peut retirer qui pousse sur `main`.
- **Compte GitHub séparé pour Claude** (les permissions de l'application ont été mises à jour par Houssem le 13/11) : écarté le 23/10 parce que la protection de `main` suffisait ; rouvert tant que `main` n'est pas protégée.
- **Double authentification Microsoft (Bing)** : ce compte ne publie rien sur le site. Risque : perte de l'accès aux statistiques de Bing.
- **Renouvellement automatique du domaine** : domaine acheté le 22/10/2026, échéance constatée au 22/10/2027 (registre, 11/11). Risque faible avant l'automne 2027.
